# GPF

GPF manages the genotypes and the phenotypes of families, and serves them through a web API.

## Language

**Partial grant**:
The access of a user to a parent dataset that comes from grants on some of its child studies. The user holds neither the parent nor all of its children. Under a partial grant, the gated routes of the parent serve only the data of the allowed child studies, or refuse the request.
_Avoid_: partial rights, partial permissions
